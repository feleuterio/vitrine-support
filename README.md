# Vitrine: Coleção de Relógios — Suporte

Vitrine é um app iOS para colecionadores de relógios. Local-first: seus dados
ficam no seu aparelho e, se você ativar, no seu próprio iCloud.

## Precisa de ajuda?

**Abra uma issue aqui neste repositório** (aba *Issues* → *New issue*) descrevendo
o problema ou a sugestão — é o canal oficial de suporte da Vitrine.
Se preferir, escreva para fabio.gimenez.eleuterio@gmail.com.

## Perguntas frequentes

**Onde ficam meus dados?**
No seu aparelho (banco SQLite local) e, com iCloud ativo, no container privado
do app no SEU iCloud. Nenhum dado passa por servidores nossos — não temos servidores.

**Como sincronizo entre aparelhos?**
Instale a Vitrine nos aparelhos com a mesma conta iCloud. A sincronização
acontece ao abrir o app, ou pelo botão "Sincronizar agora" na aba Rotação.

**Como faço backup?**
Além do iCloud, você pode exportar a coleção em CSV: aba Rotação → Dados → Exportar CSV.

**Apaguei o app. Perdi tudo?**
Com iCloud ativo, reinstale e sincronize: coleção e fotos voltam.

**Limite de 10 relógios?**
A versão gratuita guarda até 10 peças. Uma versão para coleções maiores está a caminho.

## Política de privacidade

A Vitrine não coleta, não transmite e não compartilha nenhum dado pessoal.
Não há contas, análises de uso (analytics), anúncios ou rastreadores.
Todos os dados (relógios, fotos, registros de uso, lista de desejos) permanecem
no dispositivo do usuário e, opcionalmente, no iCloud pessoal do usuário via
sincronização padrão da Apple. Nada disso é acessível ao desenvolvedor.
